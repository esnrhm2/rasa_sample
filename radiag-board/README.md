# Radiag Board — Intro

Static product intro page for **Radiag Board** (framework deferred).

## Open locally

```bash
# from repo root
open radiag-board/index.html
# or serve the folder, e.g.
python3 -m http.server 8080 --directory radiag-board
```

Then visit `http://localhost:8080/`.

## Pages

| File | Role |
|---|---|
| `index.html` | Product intro / landing |
| `overview.html` | Placeholder shell for Board entry CTA |
| `assets/logo.png` | Official Radiag Board product logo |
| `css/styles.css` | Brand tokens + layout |
| `js/main.js` | Light motion helpers |
